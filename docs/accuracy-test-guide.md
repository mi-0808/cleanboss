# 検出精度テスト手順書

## 目的

GPT Vision APIの着用チェック精度を検証し、このまま使い続けるか別のAIに切り替えるかを判断する。

## 条件

- 作業者: 1人
- 所要時間: 約30分
- 期限: 1週間以内に実施
- 必要なもの
  - PC・スマホなどカメラのついた端末（プロトタイプが動作するもの）
  - クリーン番長サイト（https://cleanboss-1.vercel.app/）
  - クリーンウェア一式（頭巾、マスク（私物で可）、手袋）
  - 記録用スプレッドシート（後述のテンプレートを使用）

## テストの流れ

### ステップ1: 記録シートを準備する

Googleスプレッドシートに以下の列を作成する。

- A列: No.（1, 2, 3, ...）
- B列: 意図した状態（例: 「マスクを鼻の下まで下げた」）
- C列: 結果（検知成功 / 検知正常）
- D列: 備考（気になった点があれば）

記録ルール
- 不備を意図的に作った → AIが不備を検知できた → **検知成功**
- 不備を意図的に作った → AIがOKと判定した → 空欄（見逃し）
- 正常に着用した → AIもOKと判定した → **検知正常**
- 正常に着用した → AIが不備と判定した → 空欄（過検出）

### ステップ2: テストを実施する（計40回）

自分1人でクリーンウェアを着用し、クリーン番長を開いて検出→判定を繰り返す。1回あたり1分程度で回せる。

**OKパターン（20回）**

全項目正しく着用した状態で20回検出する。立ち位置や角度を少しずつ変える。

- 期待する結果: 検知正常

**NGパターン（20回）**

以下から選んで1回ずつ検出する。各パターンを2〜3回ずつ繰り返してもOK。

- マスクを顎にかける
- マスクを外す
- 前髪を大きく出す
- フードを被らない
- ゴーグルを外す
- ファスナーを胸元まで大きく開ける
- 袖をまくって手首を露出させる
- 手袋を片手外す
- 手袋を両手外す
- 上記から追加で繰り返し（複数の不備を同時に作るなどでもOK）

- 期待する結果: 検知成功

### ステップ3: 結果を集計する

シートの結果を数える。

不備の見逃し（最重要）
- NGパターンの合計: 20回
- そのうち「検知成功」の数: ___回
- 検知成功率: 検知成功の数 ÷ 20 × 100 = ___%
- 目標: 90%以上（18回以上が検知成功）

過検出
- OKパターンの合計: 20回
- そのうち「検知正常」の数: ___回
- 検知正常率: 検知正常の数 ÷ 20 × 100 = ___%
- 目標: 90%以上（18回以上が検知正常）

### ステップ4: 判断する（全員で実施）

**GPT継続でOK**
- 検知成功率・検知正常率ともに 90%以上
- → プロンプト微調整のみで本番投入可能

**プロンプト改善で対応**
- どちらかが 70〜90%
- → 弱いパターンを特定してプロンプトを調整し再テスト
- → 2回目のテストで目標達成すればGPT継続

**AI切り替えを検討**
- どちらかが 70%未満
- → Claude Vision、Gemini等で同じテストを実施して比較
- → 最も精度の高いモデルを採用

## 注意事項

- 本番と同じ環境（同じ場所、同じ照明、同じiPad位置）で行うこと
- 気になる結果は同じパターンで2〜3回試して傾向を確認する
- AI判定結果のスクリーンショットも撮っておくと後で共有しやすい
